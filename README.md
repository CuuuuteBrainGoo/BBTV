一个面向 **Android TV 大屏与遥控器**的 Bilibili 客户端：浏览视频 → 选择分集 → 播放、切换画质与弹幕字幕。

> 自己用的电视端工具，把推荐、动态、影视、直播和观看记录放到大屏上，常用操作用遥控器完成。项目持续开发，当前功能、使用方法和已知限制见项目说明。

**安装包：** [ARM64 精简 Release · 3.21 MiB](https://github.com/CuuuuteBrainGoo/BBTV/releases/download/v1.3.5/BBTV-1.3.5-release-arm64-small.apk) · [通用 Release · 3.22 MiB](https://github.com/CuuuuteBrainGoo/BBTV/releases/download/v1.3.5/BBTV-1.3.5-release-universal.apk) · [Debug · 16.17 MiB](https://github.com/CuuuuteBrainGoo/BBTV/releases/download/v1.3.5/BBTV-1.3.5-debug-universal.apk)
