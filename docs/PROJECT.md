# BBTV 项目说明

BBTV 是面向 Android TV、大屏和遥控器的第三方 Bilibili 客户端，也是探索 AI 辅助软件开发的学习项目。当前公开正式版为 **1.4.48 / 10448**；安装包和校验文件见[发布页](https://github.com/CuuuuteBrainGoo/BBTV/releases/tag/v1.4.48)。

## 功能与操作

- 浏览推荐、分区、动态、影视、直播，搜索并查看视频详情。
- 分 P、分集、合集／播放列表，选择实际可用画质、音质和倍速，上一项／下一项、刷新与循环播放。
- 控制栏即时设置与设置页同步；默认画质用于下次进入视频，当前画质只影响本次播放，不修改默认值。
- 视频接口字幕默认关闭，可调语言、字号和背景；弹幕可调透明度、字号、占屏范围、速度和屏蔽规则，互动弹幕只显示且限密度。
- 本机观看记录无需登录，退出账号保留记录；收藏、关注等功能按账号登录状态与服务权限提供。
- 卡片按实际可用宽度自动排满，四档大小与手动列数覆盖；普通视频与影视海报分别设置。主要目标为正常横屏和超宽屏，不针对竖屏、方屏或手表优化。
- 调整皮肤、界面字号、启动页面、启动焦点、首页分区、侧栏栏目与按钮顺序；推荐和热门保留，触屏支持长按拖动排序。
- 可显示只读评论；选集、推荐、上一项／下一项、刷新、循环等扩展控制栏按钮可在界面设置开启，默认隐藏。

| 场景 | 默认操作 |
|---|---|
| 页面浏览 | 方向键移动焦点，OK 确认，返回键回到上一层 |
| 影视详情 | 加载完成选中播放，方向键选集；无剧集时回到返回按钮 |
| 非播放卡片 | 菜单键刷新当前页面 |
| 首页分区 | OK 切换或刷新后焦点留在标签，按下键进入卡片 |
| 播放控制栏 | 菜单键打开，再按菜单键或返回键关闭 |
| 播放侧栏 | 上键推荐，下键分 P／播放列表；只有一个分 P 不单列，无合集时可回退 UP 投稿 |
| 关闭播放侧栏 | 返回键关闭，回到视频播放 |
| 触屏播放 | 单击呼出控制栏，双击播放／暂停，水平滑动定位，长按临时 2 倍速 |
| 亮度／音量 | 视频左侧上下滑调亮度，右侧上下滑调音量，中央显示操作条 |
| 字幕 | 播放设置总开关与可选 CC 控制栏按钮联动 |

触屏手势和遥控器映射可调整。开启省内存模式时以 OK 确认切换页面；关闭时可随导航焦点切换。

## 安装包与验证

本版通用 Release 为 3.71 MiB，Debug 为 16.62 MiB；没有单独发布 ARM64 精简包。通用包包含 arm64-v8a、armeabi-v7a、x86_64。Release 启用代码与资源压缩，沿用既有本地测试证书以支持覆盖升级；未包含签名私钥。

370 个 JVM 测试用例通过（0 失败／错误／跳过）。两个安装包已核对版本、架构、签名、对齐和 SHA256。

1.4.48 已在模拟器验证电影与番剧详情的播放焦点、方向键选集、进入播放及返回，以及触摸后切回遥控操作；测试设置和观看记录已恢复。电视、手机尚未进行本版复测，未逐个验收全部影视分区，空剧集与失败重试分支尚缺运行验证。此次不是完整性能回归，包大小不等于运行性能。

## 技术与构建

| 部分 | 当前选型 |
|---|---|
| 语言／构建 | Kotlin 2.0.21、JDK 17、AGP 8.7.3、Gradle 8.11.1 |
| 界面 | Jetpack Compose、Material3、遥控器焦点组件 |
| 播放 | Media3 1.4.1、DASH／HLS |
| 网络／图片 | OkHttp 4.12、Coroutines 1.9、Coil 2.7 |
| Android | minSdk 21，compileSdk／targetSdk 35；应用 ID `top.bilitv` |

`app/src/main/java/top/bilitv/` 中，`data` 负责接口、账号、本地数据和设置，`player` 负责选流和播放适配，`ui` 负责页面导航与控件，`util` 为公共工具。`app/src/test/` 是 JVM 测试，`docs/assets/` 保存 README 图片。

配置 JDK 17 与 Android SDK 35，通过环境变量或未提交的 `local.properties` 指定 SDK 路径。在项目根目录执行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
.\gradlew.bat :app:assembleRelease
.\gradlew.bat -PbbtvUniversal=true :app:assembleRelease
```

依次生成 Debug、ARM64 Release 和通用 Release。输出位于 `app/build/outputs/apk/`，Release 需自行签名。Media3 固定1.4.1，调整版本前需重新检查真实 HEVC 流解析和播放兼容性。

## 已知限制

- 上游接口可能变化；登录不保证全部内容或高画质可用，不能绕过服务权限。
- 推荐提供 Web／App 来源、个性化选项和一次失败回退；支持范围内的普通视频详情和取流可使用 App/gRPC，影视、收费或不支持的详情仍回退 Web，并非整站接口都改为 App。
- 界面语言支持跟随系统／中文／英文；主要页面和设置已有中英文资源，部分文案与格式仍需完善，服务端内容不翻译。
- 非空账号列表的多页边界、真实充电视频试看、部分直播切档／线路、字幕和触屏组合操作仍需更多设备验收。
- 不提供编写／发送弹幕、本地字幕导入、人像防挡、内置截图分享、时钟或图片背景。播放诊断默认关闭，仅高级模式可启用；日志仅本地查看。

安装包仅供学习参考和体验，说明见[README](../README.md)。
